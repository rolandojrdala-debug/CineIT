# CineIT 🎬 
**Your Cinema Companion**

## About the Project
CineIT is a platform designed to keep your movie plans in one place. Whether you are tracking watchlists, managing cinema bookings, or organizing ticket details, CineIT provides a single, secure account for all your cinema needs. 

## Features
* **User Authentication:** Secure sign-up and login functionality for personalized accounts.
* **Booking & Watchlist Management:** Keep track of your next great night out and previous ticket details.
* **Theme Toggle:** Built-in Light/Dark mode for a customized viewing experience.
* **Modern UI:** Clean, responsive interface using the Manrope font family.

## Tech Stack
* **Frontend:** HTML5, CSS3, Vanilla JavaScript
* **Backend:** Node.js, Express.js
* **Database:** SQL (PostgreSQL/MySQL)
